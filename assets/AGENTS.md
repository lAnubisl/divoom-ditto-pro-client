# Sample media guidance

- `demo.png` and `mail-14.gif` are documented samples and linked test fixtures.
  Preserve their paths unless updating the README and referencing test project files.
- Changes to these files can change test expectations. Check decoding, pixel, frame,
  and duration assertions before replacing media.
- Keep sample assets portable and small enough for the documented upload limits.
- Preserve the animated envelope sample's meaning (number 14) when updating the
  corresponding README example, and preserve third-party attribution where applicable.
